只有私有頻道需要認證，公共行情頻道可以直接訂閱。

## API Key 簽名

在 `auth` 中傳入 API Key 和本地生成的 HMAC-SHA512 簽名：

```json
{
  "method": "api_key",
  "key": "YOUR_API_KEY",
  "sign": "HEX_SIGNATURE"
}
```

直接訂閱私有頻道時，簽名原文為：

```text
channel=pred.orders&event=subscribe&time=1720000000123
```

使用 API Secret 作為 HMAC-SHA512 金鑰並輸出十六進制摘要。API Secret 不能發送到服務端。

## 私有訂閱示例

```json
{
  "t": 1720000000123,
  "id": "private-1",
  "op": "subscribe",
  "ch": "pred.orders",
  "payload": {
    "all": true
  },
  "auth": {
    "method": "api_key",
    "key": "YOUR_API_KEY",
    "sign": "HEX_SIGNATURE"
  }
}
```

`pred.usertrades`、`pred.positions` 和 `pred.settlements` 使用相同的 API Key 認證方式。
