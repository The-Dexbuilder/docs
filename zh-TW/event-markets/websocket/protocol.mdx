消息使用 JSON。請求中的 `t` 必須與服務端時間相差不超過 60 秒，`id` 必須是字串或整數。

## 訂閱

```json
{
  "t": 1720000000123,
  "id": "req-1",
  "op": "subscribe",
  "ch": "pred.depth",
  "payload": {
    "items": [
      {
        "token_id": "ge_token-yes",
        "level": 20
      }
    ]
  }
}
```

取消訂閱時使用相同的頻道和 payload，並將 `op` 設定為 `unsubscribe`。私有頻道還需要 `auth`；私有頻道支援 `{"all": true}`，公共頻道必須使用 `items`。

## ACK

成功：

```json
{
  "t": 1720000000124,
  "id": "req-1",
  "trace_id": "trace-1",
  "op": "subscribe",
  "ch": "pred.depth",
  "err": null,
  "result": {
    "status": "success"
  }
}
```

失敗：

```json
{
  "t": 1720000000124,
  "id": "req-1",
  "trace_id": "trace-1",
  "op": "subscribe",
  "ch": "pred.depth",
  "err": {
    "code": 2,
    "msg": "invalid depth item"
  },
  "result": {
    "status": "fail"
  }
}
```

## 快照和更新

緩存的初始資料使用 `type: "snapshot"`，後續事件使用 `type: "update"`。消息包含 `ch`、`err: null` 和頻道對應的 `result`。

單次請求最多 100 個訂閱項，單連接最多 10,000 個訂閱。重連後需要重新訂閱；私有頻道應透過 REST 介面恢復帳戶目前狀態。
