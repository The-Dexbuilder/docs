使用私有 `pred.orders` 和 `pred.usertrades` 跟蹤訂單生命週期和成交，使用 `pred.positions` 和 `pred.settlements` 跟蹤帳戶狀態。

## 連接位址

```text
wss://broker.dexbuilder.com/ws/dex-builder/prediction
```

## 訂閱

使用 API Key 簽名認證：

```json
{
  "t": 1720000000123,
  "id": "orders-1",
  "op": "subscribe",
  "ch": "pred.orders",
  "payload": {
    "all": true
  },
  "auth": {
    "method": "api_key",
    "key": "YOUR_API_KEY",
    "sign": "HEX_SIGNATURE"
  }
}
```

## 推送內容

訂單包含標識、方向、價格、數量、狀態和時間戳；使用者成交包含成交、訂單、角色、費率、成交價格、數量和確認狀態；倉位包含數量、平均價格、結算狀態、可用數量、鎖定數量和可領取金額。文檔不描述標記價格欄位。

## 狀態恢復

WebSocket 是事件推送，不能替代 REST 查詢。連接或重連後：

1. 訂閱需要的私有頻道。
2. 透過對應 REST 介面查詢訂單、成交、倉位和帳戶目前狀態。
3. 使用標識和時間戳應用後續 WebSocket 更新。

客戶端請求中不要暴露內部使用者 Header 或 broker 帳戶標識。
